# Ятзи (Yahtzee)

Браузерная игра «Ятзи» на русском языке: пять кубиков, три броска за ход, 13 категорий в таблице очков. Играть можно против компьютера или вдвоём на одном устройстве.

> Статус: этапы 1–4 реализованы (логика, интерфейс, режимы с компьютером, анимация, правила, «Новая игра»). Рекорды в `localStorage` пока не сделаны.

## Цели проекта

- Один файл `index.html` (HTML + CSS + JS), без фреймворков, сборки и внешних зависимостей. Открывается двойным кликом и легко публикуется на GitHub Pages.
- Код разделён на независимые блоки (логика, отрисовка, управление), чтобы при росте проекта файл можно было без переписывания разбить на `style.css` и `game.js`.
- Вся игровая логика подсчёта очков написана чистыми функциями, не зависящими от интерфейса.
- Адаптивная вёрстка для телефона, светлая и тёмная темы через `prefers-color-scheme`.

## Режимы игры

| Режим | Описание |
|---|---|
| Против компьютера | Человек и простой компьютерный соперник ходят по очереди |
| Вдвоём на одном устройстве | Два игрока по очереди ходят на одном экране (хот-сит) |

Режим «один игрок» и онлайн-игра по сети не планируются.

## Правила игры

### Ход
За ход игрок бросает пять кубиков до трёх раз. После первого и второго броска можно зафиксировать любые кубики (они не перебрасываются) и снять фиксацию. После последнего броска (или раньше) игрок обязан записать результат в одну свободную категорию. Игра заканчивается, когда у всех игроков заполнены все 13 клеток.

### Категории

**Верхняя секция** — сумма очков по выбранной грани:

| Категория | Очки |
|---|---|
| Единицы, Двойки, Тройки, Четвёрки, Пятёрки, Шестёрки | Сумма кубиков с этой гранью |

Бонус **+35**, если сумма верхней секции равна 63 или больше.

**Нижняя секция:**

| Категория | Условие | Очки |
|---|---|---|
| Сет | Три и более одинаковых | Сумма всех кубиков |
| Каре | Четыре и более одинаковых | Сумма всех кубиков |
| Фулл-хаус | Три одинаковых и два одинаковых | 25 |
| Малый стрит | Четыре подряд (например 1-2-3-4, повторы не мешают) | 30 |
| Большой стрит | Пять подряд (1-5 или 2-6) | 40 |
| Ятзи | Пять одинаковых | 50 |
| Шанс | Любая комбинация | Сумма всех кубиков |

Если комбинация не выполнена, в клетку записывается 0.

### Повторный ятзи и жокер

- Если выпал ятзи, а в клетке «Ятзи» уже стоит 50, игрок получает **бонус +100**.
- Если выпал ятзи, а клетка «Ятзи» уже занята (50 или 0), действует **правило жокера**. Записать результат можно только так:
  1. в соответствующую клетку верхней секции, если она свободна;
  2. иначе в любую свободную клетку нижней секции (фулл-хаус и стриты при этом дают полные очки 25 / 30 / 40);
  3. иначе в любую свободную клетку верхней секции (получится 0).
- Ятзи без жокера (когда клетка «Ятзи» ещё свободна) в клетку «Фулл-хаус» даёт 0: пять одинаковых не считаются фулл-хаусом по официальным правилам.

### Итог
Сумма верхней и нижней секций плюс бонусы (35 и 100 за каждый повторный ятзи). Побеждает игрок с наибольшей суммой.

## Состояние игры

Всё состояние хранится в одном объекте:

```js
{
  players: [{ name, scores: { ones: null, ..., chance: null }, yahtzeeBonuses: 0 }],
  current: 0,                         // индекс текущего игрока
  dice: [1, 1, 1, 1, 1],              // значения кубиков
  held: [false, false, false, false, false], // зафиксированные кубики
  rollsUsed: 0,                       // номер броска в ходе (0..3)
  gameOver: false
}
```

Значение `null` в таблице очков означает свободную клетку.

## Компьютерный соперник

Компьютер принимает решения по ожидаемой ценности, а не по простому правилу:

1. **Какие кубики оставить.** Для каждого варианта (оставить любой набор кубиков) он считает, какие комбинации выпадут при добросе и с какой вероятностью, и заглядывает на один бросок вперёд, если их осталось два. Если останавливаться выгоднее, чем добрасывать (например, уже есть большой стрит), он записывает результат сразу.
2. **Куда записать.** Каждая клетка оценивается как «очки минус то, сколько эта клетка в среднем даёт при хорошей игре» плюс изменение вероятности бонуса 35 за верхнюю секцию и +100 за повторный ятзи. Так он не тратит ятзи и шанс на слабые броски, а сильные броски отправляет в клетки, где они ценнее.
3. Правило жокера он соблюдает: выбирает только из разрешённых клеток.

В одиночной симуляции на одинаковых бросках прежний «жадный» компьютер (оставлял самое частое значение и брал максимум очков) набирал около 177 очков за партию, а нынешний около 240–250. Решение занимает десятки миллисекунд.

## План работ

Работа идёт по этапам. После каждого этапа делается отдельный коммит, и следующий этап начинается только после подтверждения.

### Этап 1. Игровая логика
- Бросок пяти кубиков, до трёх бросков за ход
- Фиксация и разблокировка кубиков
- 13 категорий и чистые функции подсчёта
- Бонусы 35 и 100, правило жокера
- Конец игры при заполнении всех клеток

### Этап 2. Интерфейс
- Пять кубиков с точками, нажатие фиксирует кубик
- Кнопка «Бросить» и счётчик оставшихся бросков
- Таблица очков: у свободных категорий показываются возможные очки для текущего броска, нажатие записывает результат
- Адаптивная вёрстка, светлая и тёмная темы, интерфейс на русском

### Этап 3. Режимы и соперник
- Выбор режима при запуске: против компьютера или вдвоём на одном устройстве
- Передача хода между игроками
- Компьютерный соперник по стратегии выше

### Этап 4. Дополнительно
- Анимация броска кубиков
- Экран правил
- Кнопка «Новая игра» с подтверждением

### Возможное развитие (пока не в плане)
- Рекорды в `localStorage` с корректной работой при недоступном хранилище
- Режим «один игрок»
- Разбиение `index.html` на `style.css` и `game.js`
- Более умный компьютерный соперник

## Запуск

Откройте `index.html` в браузере. Сервер и установка зависимостей не нужны.

## Тесты

Автотесты проверяют чистые функции логики (фулл-хаус, стриты, нули, бонусы 35 и 100, жокер, броски, конец игры, выбор компьютера, превосходство нового компьютера над прежним «жадным»). Нужен Node.js 20+, зависимостей нет:

```
node --test tests/logic.test.js
```

Тесты берут код из `index.html` между маркерами `// <logic>` и `// </logic>`.
