# Ятзи (Yahtzee)

Браузерная игра «Ятзи» на русском языке: пять кубиков, три броска за ход, 13 категорий в таблице очков.

> Этот сайт сделан с помощью искусственного интеллекта ([Claude](https://claude.ai/code) от Anthropic) по задачам автора проекта.

## Как играть

Откройте `index.html` в браузере. Сервер, сборка и зависимости не нужны. Работает и с телефона, есть светлая и тёмная темы.

- **Против компьютера** — три уровня: «Лёгкий» (до 200 очков за партию), «Нормально» (около 200), «Эксперт» (идеальная игра, около 255).
- **Вдвоём на одном устройстве** — игроки ходят по очереди.

## Правила в двух словах

- За ход до трёх бросков; после первого и второго можно зафиксировать кубики.
- Результат записывается в одну из 13 клеток; игра идёт, пока все клетки не заполнены.
- Верхняя секция даёт бонус +35 при сумме 63 и больше.
- Повторный ятзи при 50 в клетке «Ятзи» даёт +100; если клетка «Ятзи» занята, действует правило жокера.
- Побеждает игрок с наибольшей суммой.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | вся игра (HTML, CSS, JS) |
| `optimal.js` | таблица для уровня «Эксперт» (генерируется) |
| `tools/build-optimal.js` | строит `optimal.js`: `node tools/build-optimal.js` |
| `tests/logic.test.js` | автотесты логики: `node --test tests/logic.test.js` (нужен Node.js 20+) |

Код игры разделён на блок логики (`// <logic>`, без интерфейса) и блок интерфейса (`// <ui>`).
